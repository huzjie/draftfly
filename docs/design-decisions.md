# 设计决策

1. **零依赖纯 Python**：张量、n-gram、采样、HTTP 全部标准库实现，克隆即跑。
2. **确定性可复现**：md5 派生 RNG，任意两次运行逐位一致，评测可进 CI。
3. **延迟建模分离**：`cost_ms` 是抽象成本，`real_clock` 切换真实/虚拟计时，测试不 sleep。
4. **q 与采样来源严格一致**：接受采样用的 q 就是草稿实际采样的过滤后分布（含温度/top-k/top-p），保证拒绝采样数学正确。
5. **控制 token 屏蔽**：pad/bos/unk 在模型层屏蔽，eos 保留作停止信号。
6. **贪心一致性可断言**：贪心模式下输出 == 目标贪心输出，这是最硬的正确性保证。
