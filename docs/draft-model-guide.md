# 草稿模型选型

投机解码的加速上限由「草稿速度」与「接受率」共同决定。选草稿模型的要点：

1. **足够小、足够快**：草稿耗时 / 目标耗时 的比值越小，加速上限越高。
2. **尽量贴近目标**：草稿分布与目标越近（TV 距离越小），接受率越高。
3. **复用缓存**：像 DFly2 那样复用目标 KV cache + 稀疏索引，做到零额外显存。

经验法则：接受率 80% 左右已能带来显著加速；草稿比目标快一个数量级时，K 可以
取到 4~8。

用 `python -m draftfly eval` 看「接受率 vs 草稿能力（skill）」曲线，直观感受
草稿能力对接受率的影响。
