# 投机解码算法

## 动机

自回归生成是串行的：第 i 个 token 的生成依赖前 i-1 个 token，每次都要跑一遍
大模型。大模型前向的瓶颈往往不是算力而是「显存带宽」——一次前向只吐一个
token，带宽利用率极低。

投机解码把「串行生成」变成「并行验证」：

1. 草稿模型（小、快）连猜 K 个 token。
2. 目标模型（大、准）单次前向，对这 K+1 个位置一次算出概率分布。
3. 用接受采样逐位判断草稿 token 对不对，留下对的、修正错的。

## 加速比

理论加速比 ≈ K / (1 + K · (草稿耗时 / 目标耗时))。

草稿越快（比值越小）、K 越大、接受率越高，加速越明显。上限约等于 K（当草稿
耗时可忽略时）。

## 为什么不损失质量

接受采样（rejection sampling）保证：无论草稿猜什么，最终输出的分布与目标模型
纯自回归的分布**严格一致**。贪心模式下更是逐 token 一致（可断言）。
