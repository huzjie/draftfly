# FAQ

**Q：不接真实模型能跑吗？**
A：能。内置确定性 n-gram 草稿/目标模型对，`doctor`/`generate`/`bench`/`eval` 全链路零依赖可跑。

**Q：为什么采样模式输出看起来不连贯？**
A：内置语料极小（故意为之，保证零依赖），字符级 n-gram 采样质量受限。换真实模型或更大语料即可。贪心模式输出干净且与目标一致。

**Q：怎么接真实模型？**
A：实现 `ModelAdapter`（token 级），或把两个 OpenAI 兼容端点接给 `TextSpeculator`（文本级）。

**Q：加速比怎么来的？**
A：`cost_ms` 建模各模型单次前向成本，投机解码把目标一次前向摊到 K 个 token 上。接真实后端后加速比由真实延迟决定。

**Q：会不会输出错？**
A：不会。接受采样保证输出分布与目标模型一致；贪心模式逐 token 一致（可断言）。
